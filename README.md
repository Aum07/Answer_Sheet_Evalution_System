This repository is the first version, built as my final-year BTech project at D Y Patil International University (2025). It grades free-text exam answers from PDFs using sentence embeddings and an ordinal regression model, served through FastAPI.

## What changed in the new version

This version scored **QWK 0.89** against its training data, which was 4,500 answers generated by an LLM. When I rebuilt it, I tested it on **2,273 real answers marked by two teachers**, and found that the score didn't hold up: on real students it dropped to 0.31.

The rebuilt version fixes that and adds a lot more:

- Retrained and tested on real, teacher-marked answers, using the agreement between the two teachers as the realistic target
- An LLM grader, and a combined model that agrees with each teacher about as well as they agree with each other
- Tests for cheating (keyword lists, restating the question, filler) with defences that rarely affect honest answers
- A tested code structure, Docker, CI and a live demo
